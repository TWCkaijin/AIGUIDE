# Spec Delta

## Purpose

在使用者可能遇到緊急狀況時，提供求助入口並通報院內人員，讓人員能找到使用者。

## ADDED Requirements

### Requirement: 顯示求助按鈕
系統判斷使用者可能為緊急狀況時，SHALL 彈出「我需要求助」按鈕。(判斷依據待確認 #10；是否常駐待確認 #12)

#### Scenario: 疑似緊急狀況
- **WHEN** 系統判斷使用者可能為緊急狀況
- **THEN** 畫面彈出「我需要求助」按鈕

### Requirement: 求助通報
使用者按下「我需要求助」後，系統 MUST 直接通報院內人員使用者的地點及使用者特徵，並引導使用者到附近顯眼地標。(使用者特徵內容與位置取得方式待確認 #11)

#### Scenario: 按下求助
- **WHEN** 使用者按下「我需要求助」
- **THEN** 院內人員收到包含使用者地點與特徵的通報，且使用者畫面顯示前往附近顯眼地標的引導
