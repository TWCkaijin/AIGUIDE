# Spec Delta

## Purpose

在部門或路線臨時變動時更新系統資料，並即時通知正在使用導引且受影響的使用者。

## ADDED Requirements

### Requirement: 臨時變動的更新者
各部門 SHALL 能更新自身部門的資訊；護理行政人員 SHALL 能維護資料。(部門更新是否需審核待確認 #9)

#### Scenario: 部門更新位置
- **WHEN** 某部門在系統上更新自身位置
- **THEN** 系統採用更新後的位置進行導引

### Requirement: 導引中使用者註冊
使用者開始路線時 MUST 註冊到系統，使後台能與該使用者的前端建立連結。

#### Scenario: 開始路線
- **WHEN** 使用者開始一段導引路線
- **THEN** 後台建立與該使用者前端的連結

### Requirement: 通知受影響使用者
路線或站點受臨時變動影響時，系統 MUST 第一時間通知受影響的使用者並建議更改路線。

#### Scenario: 走道封閉
- **WHEN** 某使用者目前路線經過的站點或路線因臨時變動受影響
- **THEN** 系統立即通知該使用者，並提供更改後的建議路線
