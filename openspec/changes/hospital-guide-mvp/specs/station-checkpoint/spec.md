# Spec Delta

## Purpose

由站點人員在現場確認病人的就醫進度，作為系統判斷站點完成與病人是否走對站的依據。

## ADDED Requirements

### Requirement: 站點人員登錄完成
站點人員 SHALL 在病人完成該站後於系統登錄，醫院系統自動同步至醫院通。(原型為 mock)

#### Scenario: 完成抽血
- **WHEN** 站點人員登錄某病人已完成抽血
- **THEN** 醫院通將該病人的抽血站標記為完成

### Requirement: 到站核查
病人抵達下一站時，站點人員 SHALL 核查病人是否走對站點、前一站是否已完成。

#### Scenario: 病人走錯站
- **WHEN** 站點人員核查發現病人走錯站
- **THEN** 系統不執行任何動作，由站務人員引導病人回到正確站點
