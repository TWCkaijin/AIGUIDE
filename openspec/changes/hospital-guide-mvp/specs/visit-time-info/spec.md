# Spec Delta

## Purpose

讓使用者在就醫過程中掌握各段所需時間與叫號進度，減少非預期的等待。

## ADDED Requirements

### Requirement: 顯示時間資訊
系統 SHALL 顯示以下時間資訊：走到下一站需要多久、到站後預計要等多久、掛號號碼目前叫到幾號、整趟就醫預計多久完成。(暫定四項)

#### Scenario: 查看下一站
- **WHEN** 使用者查看今日行程中的下一站
- **THEN** 畫面顯示步行時間、預計等候時間、目前叫號與整趟預估完成時間

### Requirement: 叫號與等候資料來源
預計等候時間與目前叫號 SHALL 透過串接醫院叫號系統取得。(原型為 mock；步行時間與整趟預估的來源待確認 #7)

#### Scenario: 叫號更新
- **WHEN** 醫院叫號系統的叫號改變
- **THEN** 系統顯示的目前叫號隨之更新

### Requirement: 預測抵達時間與人流
系統 SHALL 提供抵達時間與人流的預測。(原型為 mock)

#### Scenario: 查看人流
- **WHEN** 使用者查看某站點資訊
- **THEN** 系統顯示該站的預測抵達時間與人流資訊
